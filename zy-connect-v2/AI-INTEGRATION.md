# 给开发 AI 的接入任务｜纸燕 ZY-Connect v2

你是生产工具的编码 AI。请先阅读 [v2 规范](./README.md) 和 [Node SDK](./sdk/zy-connect-v2.mjs)。注意：旧目录 `zy-connect/` 是 v1 协议，**不得安装旧 SDK、旧 pairing.json 或旧缓存视频副本**。

## 用户目标

仅为当前内容生产工具添加独立、可关闭的纸燕作品交付功能。**不修改纸燕发布引擎、不实现平台登录、不控制发布开关、不直接向任何社交平台投稿**。

## 实现要求

1. 确认生产工具真正的“成片导出成功且文件关闭”事件、现有 outputDir 设置来源、真实标题/描述/话题/封面和可重试唯一作品 ID。不要臆造接口、账号或元数据。
2. 首选复制 [v2 Node SDK](./sdk/zy-connect-v2.mjs) 到生产工具项目，实例化 `ZyConnectV2({name, outputDir})`（目录由生产工具自行读取；普通用户不应在纸燕重复选择目录）。如生产工具为 Python/其他语言，可按 [v2 HTTP 合约](./README.md#http本机回环) 做等效、可测试的轻量适配，**不得复用 v1 Python SDK**。
3. 首次启动调用 `sdk.requestConnection()`；纸燕界面显示待授权生产工具，用户明确点击“允许连接”。生产工具接着通过 `sdk.checkApproval()` 或 `sdk.waitForApproval()` 领回专用 Bearer 凭据并持久保存，**无需用户手抄配对码、接口地址或密钥**。
4. 每次成片完成后调用 `sdk.deliver({contentId, videoPath, title, description, hashtags, coverPath, ...})`。只能提交用户已授权本机目录内实际存在且完整的原视频路径。**不要复制、移动、缓存或上传 MP4；只持久化小型 JSON 元数据和回执。**
5. 保留 SDK Outbox、离线重试和去重逻辑。只把 HTTP 202/ACK 标为“纸燕已接收”，绝不能显示“已经公开发布”。收到 401/403/410 时撤销本机旧授权并提示重新连接。
6. 接口能力上限决定交付字段；没有的元数据留空，由纸燕补全。不要为了某个可选字段而阻塞视频接收。
7. 使用独立临时目录、独立 SQLite 数据库和模拟 MP4 进行验收：首连请求→用户确认→交付→回执→断网重试→去重→撤销/删除→不复制视频；不得操作正式社交账号、真实发布队列或重新提交旧视频。
8. 保持视频生产工具所有现有功能不变。完成后用中文简述修改了哪些文件、真实测试结果和用户唯一需要做的操作。

本版本暂不提供跨电脑/云端文件上传。对无法改源码的生产工具，让用户走纸燕“智能一键连接”或手动选择一次目录，不要向任意软件注入不可信代码。
